# Runner — endless runner с учителями

Unity 6.3 LTS (6000.3.21f1) · URP · Android (портрет) · Input System

---

## Как запустить

Unity Hub → проект **Runner** → открыть сцену `Assets/_Project/Scenes/Game.unity` → ▶ Play.

**Управление в редакторе:** стрелки или WASD. Вверх/пробел — прыжок, вниз — подкат, влево/вправо — смена полосы. Пробел на экране проигрыша — начать заново.

**Управление на телефоне:** свайпы в четыре стороны, тап для рестарта.

---

## Пересборка сцены одной кнопкой

Меню **Tools → Runner**. Каждый пункт удаляет старое содержимое сцены, создаёт нужные префабы и заново проставляет все ссылки в инспекторе.

| Пункт | Что собирает |
|---|---|
| M1 — сцена с длинным полом | Игрок и камера на прямом полу 2000 м. Для отладки движения. |
| M2 — бесконечная трасса из чанков | Генератор трассы с пулингом, без препятствий. |
| M3 — препятствия и Game Over | Плюс препятствия, столкновения, рестарт. |
| **M4 — монеты, очки и сохранения** | **Текущая рабочая сцена. Полный MVP.** |

Если что-то сломалось в сцене — жми M4, получишь чистую версию за секунду.

## Ключевые решения

**Двигается игрок, а не мир.** Проблема точности float начинается примерно на 100 000 юнитов — это 70 минут непрерывного бега на максимальной скорости. Двигать мир вместо игрока пришлось бы ценой двух систем координат в камере, партиклах и анимациях. Если однажды понадобится — добавляется за час.

**Прыжок задаётся высотой и временем, а не ускорением.** В инспекторе крутятся `Jump Height` (2.2) и `Jump Air Time` (0.75), а гравитация и сила толчка выводятся из них в `RecalculateJumpPhysics`. Так подбирать ощущение прыжка можно на понятных величинах.

**Никаких Instantiate после старта.** Чанки, препятствия и монеты живут в пулах (`ObjectPool`). На дистанции 2900 м пул не растёт: 13 чанков и 24 препятствия, FPS держится 60. Это главная защита от фризов на слабых телефонах.

**Трасса не может быть непроходимой.** Гарантия строится в три слоя, все в `ObstacleSpawner`:

1. Таблица `ObstaclePatterns` не содержит ни одной раскладки без прохода. Если в ряду нет пустой полосы, все три полосы обязаны быть одного проходимого типа (`JJJ` или `SSS`).
2. У соседних рядов обязана быть общая проходимая полоса — трассу можно пройти вообще не перестраиваясь.
3. Ряды, требующие прыжка или подката, стоят не ближе 22 юнитов друг к другу. На максимальной скорости 24 ю/с прыжок длится 0.75 с, то есть 18 юнитов; два подряд физически не успеть.

**Кинематический Rigidbody с Interpolation = None.** Интерполяция нужна, только когда физика сама двигает тело. Мы пишем Transform вручную каждый кадр, и включённая интерполяция подвешивает игрока над полом.

## Что крутить для баланса

| Где | Поле | Сейчас |
|---|---|---|
| Player → Player Controller | Start Speed / Max Speed | 8 / 24 |
| Player → Player Controller | Jump Height / Air Time | 2.2 / 0.75 |
| Player → Player Controller | Slide Duration | 0.6 |
| ChunkSpawner → Obstacle Spawner | Start Safe Distance | 45 м без препятствий на старте |
| ChunkSpawner → Obstacle Spawner | Min Action Spacing | 22 |
| ChunkSpawner → Obstacle Spawner | Coin Chance / Coins Per Chunk | 0.75 / 10 |
| GameManager → Game Manager | **God Mode** | отладка: проходить сквозь препятствия |
| ChunkSpawner → Obstacle Spawner | Log Patterns | печатать раскладки в консоль |

Кривая сложности — в `ObstaclePatterns.TierForDistance`: 0–200 м, 200–600, 600–1200, 1200+.

## Сохранения

JSON в `Application.persistentDataPath/save.json`. На macOS это
`~/Library/Application Support/RafaelGames/Runner/save.json`.

Пишется после каждого забега, при сворачивании приложения и при выходе. Битый файл не роняет игру: `SaveSystem.Load` ловит исключение и начинает новый сейв.

## Билд на телефон

1. На Android-телефоне: Настройки → О телефоне → 7 тапов по «Номер сборки», затем Настройки → Для разработчиков → **Отладка по USB**.
2. Подключить кабелем, подтвердить запрос на телефоне.
3. Unity: **File → Build Profiles** → Run Device → выбрать телефон → **Build And Run**.

Уже настроено: Android, портрет, Linear, IL2CPP, ARM64, minSdk 26, пакет `com.RafaelGames.Runner`.
