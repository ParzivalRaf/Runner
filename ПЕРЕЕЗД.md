## 1. Самый простой способ переезда

Проект уже в git и уже на GitHub — `github.com/ParzivalRaf/Runner`, ветка `main`.
Поэтому переезд = «доложить недостающее в репозиторий, отправить, склонировать».
Никаких флешек, дисков и архивов на 14 ГБ не нужно.

### На этом Mac (в Терминале, руками)

```bash
cd ~/Desktop/CampusRush

# 1. Посмотреть, что уйдёт
git status

# 2. Добавить ВСЁ, включая новый набор NewDesign
git add -A

# 3. Закоммитить
git commit -m "Переезд: набор NewDesign, свет, поезда, пандусы — всё незакоммиченное"

# 4. Отправить (тут и уйдут все 7 коммитов сразу)
git push origin main

# 5. Проверить, что ничего не осталось
git status                 # должно быть "nothing to commit, working tree clean"
git log origin/main -1     # должен быть твой последний коммит
```

Если `git add -A` ругается на `.git/index.lock` — удалить файл и повторить:
`rm -f .git/index.lock` (эта беда уже была, описана в HANDOFF.md, п. 1.4).

### На новом ПК

```bash
git clone https://github.com/ParzivalRaf/Runner.git CampusRush
```

Дальше: открыть папку через **Unity Hub → Add project**. Unity сам соберёт
`Library/` (4,5 ГБ) за 10–20 минут при первом открытии. Копировать `Library`
с Mac **не надо** — она платформозависимая и часто ломается при переносе.

**Размер того, что реально переезжает: ~130 МБ репозитория. Всё.**

## 7. Что понадобится на новом ПК, кроме файлов

Файлы — половина дела. Без этого проект не откроется:

- **Unity 6000.3.21f1** — именно эта версия. Ставить через Unity Hub, вкладка Archive. Другая версия перепишет сцены и может сломать URP-настройки.
- **Модуль под платформу**: iOS Build Support на Mac не нужен, если нового Mac не будет. На Windows — Android Build Support, если решишь собирать на телефон.
- **Аккаунт Unity** — тот же, лицензия Personal.
- **Blender** — для `ArtSource/*.blend` и скриптов запекания.
- **Git + доступ к GitHub** — логин `ParzivalRaf`, репозиторий `Runner`. Проверь, что помнишь пароль/2FA и что есть Personal Access Token: по HTTPS GitHub требует токен вместо пароля. **Сделай токен ДО отъезда** — восстанавливать доступ без старого устройства неприятно.
- **Claude Code / редактор** по вкусу.
